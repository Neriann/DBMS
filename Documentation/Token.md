# Token

## Implementation

Tokens are defined in **`src/query/parser.yy`** via `%token` directives and generated by Bison into **`parser.hpp`**
at build time.

## Tokens

| Token        | Value type    | Contains        |
|--------------|---------------|-----------------|
| `IDENT`      | `std::string` | identifier name |
| `STRING_LIT` | `std::string` | string literal  |
| `INT_LIT`    | `int`         | integer literal |

### Literals

| Token      | Lexeme |
|------------|--------|
| `NULL_LIT` | `NULL` |
