# Token

## Реализация

Токены определяются в **`src/query/parser.yy`** директивами `%token` и генерируются Bison'ом в **`parser.hpp`** 
во время сборки

## Токены

Значение передаётся через `yy::Parser::make_<TOKEN>(value)`:

| Токен        | Тип значения  | Содержит                    |
|--------------|---------------|-----------------------------|
| `IDENT`      | `std::string` | имя идентификатора          |
| `STRING_LIT` | `std::string` | строковый литерал           |
| `INT_LIT`    | `int`         | целочисленный литерал       |

### Литералы

| Токен      | Лексема |
|------------|---------|
| `NULL_LIT` | `NULL`  |

### Ключевые слова DDL

| Токен         | Ключевое слово |
|---------------|----------------|
| `KW_CREATE`   | `CREATE`       |
| `KW_DROP`     | `DROP`         |
| `KW_USE`      | `USE`          |
| `KW_DATABASE` | `DATABASE`     |
| `KW_TABLE`    | `TABLE`        |

### Ключевые слова DML

| Токен       | Ключевое слово |
|-------------|----------------|
| `KW_INSERT` | `INSERT`       |
| `KW_INTO`   | `INTO`         |
| `KW_VALUE`  | `VALUE`        |
| `KW_UPDATE` | `UPDATE`       |
| `KW_SET`    | `SET`          |
| `KW_DELETE` | `DELETE`       |
| `KW_FROM`   | `FROM`         |
| `KW_SELECT` | `SELECT`       |
| `KW_WHERE`  | `WHERE`        |
| `KW_AS`     | `AS`           |

### Типы колонок

| Токен       | Ключевое слово |
|-------------|----------------|
| `KW_INT`    | `INT`          |
| `KW_STRING` | `STRING`       |

### Модификаторы колонок

| Токен         | Ключевое слово |
|---------------|----------------|
| `KW_NOT_NULL` | `NOT_NULL`     |
| `KW_INDEXED`  | `INDEXED`      |

### Условия выборки

| Токен        | Ключевое слово |
|--------------|----------------|
| `KW_BETWEEN` | `BETWEEN`      |
| `KW_AND`     | `AND`          |
| `KW_OR`      | `OR`           |
| `KW_LIKE`    | `LIKE`         |

### Операторы

| Токен               | Лексема     |
|---------------------|-------------|
| `LPAREN` / `RPAREN` | `(` / `)`   |
| `COMMA`             | `,`         |
| `SEMICOLON`         | `;`         |
| `DOT`               | `.`         |
| `STAR`              | `*`         |
| `EQ`                | `==`        |
| `ASSIGN`            | `=`         |
| `NEQ`               | `!=`        |
| `LT` / `GT`         | `<` / `>`   |
| `LEQ` / `GEQ`       | `<=` / `>=` |
